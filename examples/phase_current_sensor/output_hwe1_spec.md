### HW-REQ-SEN-001 — Measurement range

```
ID:      HW-REQ-SEN-001
Status:  Draft
ASIL:    C
Source:  FSR-INV-002, SYS-REQ-SEN-001 (TBD)
Type:    Performance

Statement:
  The phase current sensor shall measure AC currents in the range
  -400 A to +400 A with an overload reserve of at least 150 % of the
  nominal value (>= ±600 A) without destruction or permanent calibration
  change.

Acceptance Criteria:
  - Output within linearity limits (HW-REQ-SEN-002) for I in [-400 A, +400 A]
  - No calibration error > 0.5 % FSR after a single overload event
    I = ±600 A, duration <= 10 ms

Verification method:   Test
Verification level:    Component
Traceability:          Upward FSR-INV-002 -> SG-INV-002; Downward TBD (HWE.2); Test TBD (HWE.4)
```

### HW-REQ-SEN-002 — Measurement accuracy (normal operation)

```
ID:      HW-REQ-SEN-002
Status:  Draft
ASIL:    C
Source:  FSR-INV-002; ACTION ITEM AI-01 — obtain torque constant k_T [Nm/A]
Type:    Performance

Statement:
  The phase current sensor shall output the measured current with a total
  error (offset + gain + linearity, RSS) of <= 1.5 % FSR (= ±6 A at
  FSR = ±400 A) across the full operating temperature range -40 °C to +125 °C.

Acceptance Criteria:
  - Offset error <= ±0.5 % FSR at 25 °C after calibration
  - Gain error <= ±0.8 % FSR over T in [-40 °C, +125 °C]
  - Linearity error <= ±0.5 % FSR over the full range
  - RSS total error <= 1.5 % FSR at worst-case temperature

Verification method:   Test
Verification level:    Component
WARNING: derivation needs k_T. dI_allowed = dT_allowed / k_T. See AI-01.
```

### HW-REQ-SEN-004 — Galvanic isolation

```
ID:      HW-REQ-SEN-004
Status:  Draft
ASIL:    C
Source:  SYS-REQ-ISO-001 (TBD); IEC 60664-1
Type:    Safety / Interface

Statement:
  The phase current sensor shall provide galvanic isolation between the HV
  side (DC-link potential) and the LV side (signal output) with a test
  voltage of at least 4.0 kVAC (50 Hz, 1 min) and a creepage distance
  >= 8 mm (pollution degree 2, overvoltage category III per IEC 60664-1).

Acceptance Criteria:
  - No isolation breakdown at 4.0 kVAC, 50 Hz, 1 min, 25 °C
  - Insulation resistance >= 100 MOhm at 500 VDC, 25 °C
  - Creepage and clearance >= 8 mm, verified by inspection per IPC-2221B

Verification method:   Test + Inspection
Verification level:    Component
```

### HW-REQ-SEN-005 — Fault detection and reaction (safety mechanism)

```
ID:      HW-REQ-SEN-005
Status:  Draft
ASIL:    C
Source:  FSR-INV-002; ISO 26262-5:2018 §6.4.5
Type:    Safety

Statement:
  The phase current sensor shall provide an internal self-test mechanism
  that detects the following failure modes and issues a dedicated error
  signal (active-low, galvanically isolated) within <= 100 µs:
  (a) offset drift > 3 % FSR; (b) output stuck-at-high / stuck-at-low;
  (c) supply voltage outside [VDD_min, VDD_max] per HW-REQ-SEN-007.

Acceptance Criteria:
  - Error signal within <= 100 µs after onset of mode (a), (b), (c)
  - No false positive for I in [-400 A, +400 A] normal operation
  - Error-flag levels: active-low <= 0.4 V; inactive >= VDD - 0.5 V

Verification method:   Test (Fault Injection)
Verification level:    Component
ISO 26262-5 reference: §6.4.5 (safety mechanism), Table D.1 (DC target)
```

### HW-REQ-SEN-007 — Supply voltage

```
ID:      HW-REQ-SEN-007
Status:  Draft
ASIL:    C
Source:  SYS-REQ-PWR-003 (TBD)
Type:    Interface

Statement:
  The phase current sensor shall operate from a supply of 5.0 V ± 5 %
  (4.75 V – 5.25 V) and shall set the error signal of HW-REQ-SEN-005 (c)
  on deviation outside this range.

Acceptance Criteria:
  - Accuracy per HW-REQ-SEN-002 met for VDD in [4.75 V, 5.25 V]
  - Error signal set for VDD < 4.6 V or VDD > 5.4 V (10 % hysteresis)
  - Current draw <= 25 mA at 5.0 V, 25 °C, full scale

Verification method:   Test
Verification level:    Component
```

## ASIL origin and decomposition option

```
SG-INV-002 (ASIL C)
  └─ FSR-INV-002 (ASIL C)
        └─ HW-REQ-SEN-001 … SEN-008 (ASIL C — full inheritance)
```

Decomposition option (ISO 26262-9 §5) if a qualified ASIL-C SEooC sensor is
unavailable: Channel A (main sense, e.g. shunt + diff-amp) ASIL A(C) +
Channel B (redundant, e.g. Hall, independent supply) ASIL A(C), with an
independence argument for separated supply and signal paths (no common-cause
overlap). Decide before HWE.2 kick-off (affects BOM, layout, diagnostics).
